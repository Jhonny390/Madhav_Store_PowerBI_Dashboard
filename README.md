# Madhav_Store_PowerBI_Dashboard
📊 Madhav E-commerce Sales Dashboard
📌 Overview
This project showcases an interactive E-commerce Sales Dashboard built to analyze sales, profit, customers, and product performance.
The goal is to provide clear insights that help in understanding business trends and improving decision-making.

🎯 Key Metrics
Total Sales: 438K
Total Profit: 37K
Total Quantity: 5615
Average Order Value (AOV): 120.9K
📈 Features
Monthly Profit & Loss Analysis
Top States by sales contribution
Category-wise quantity distribution
Payment Mode analysis
Top Customers identification
Profit by Sub-Category
🛠️ Tools Used
Power BI
Excel / CSV

📊 Insights
Clothing category contributes the highest sales
COD is the most used payment method
Maharashtra is the top-performing state
Some months show losses, indicating cost or pricing issues
🚀 Conclusion
This dashboard helps in identifying key business trends and supports data-driven decisions to improve overall performance
